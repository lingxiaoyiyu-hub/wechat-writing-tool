## 公众号工具通常只解决一环

搜“公众号写作工具”，大多是编辑器或排版站：有的只管排版，有的只管 AI 写作，稿子写好之后还要复制、贴图、调格式、再登后台。常见的麻烦是：

1. **写、排、图分散在三个地方**：AI 写完复制到编辑器，图片再一张张上传。
2. **排版主题不成套**：标题、分隔线、图注、引用各管各的，拼出来不统一。
3. **多账号来回切**：一个号排完再登另一个号，登录态容易乱。
4. **图片失效**：外链图片过几天打不开，草稿里全是裂图。

## 零创怎么串起来

- **公众号文风写作**：目标平台选微信公众号，按公众号的表达习惯生成，不是把头条稿直接搬过来。
- **28 套排版主题**：每套自带分隔线、图注、代码块、引用、表格等成套造型；支持整条替换分隔线、依赖标题的主题自动避开无小标题的文章。
- **配图转微信图床**：正文配图先转存微信图床，再带入草稿，避免外链失效。
- **一键存草稿**：写完直接在发布弹窗里存进公众号草稿箱，不用再复制粘贴。
- **多账号管理**：公众号扫码绑定，与头条、百家号账号一起纳入账号台账，登录态隔离。

## 常见问题

**Q：零创能直接帮我把文章群发到公众号吗？**

A：不能，也不建议任何工具这么做。微信接口只开放到草稿箱，零创把文章和排版存进草稿，最后在公众号后台确认发布。

**Q：排版主题有多少套？**

A：28 套，覆盖分隔线、图注、代码块、引用、表格等成套造型；预览弹窗可以先看效果再选。

**Q：正文图片会自动处理吗？**

A：会先转存微信图床再带入草稿，减少外链图片失效导致的裂图。

**Q：能批量存多篇草稿吗？**

A：支持批量逐篇存草稿，每篇的结果会单独显示，失败的那篇会给出原因。

**Q：多个公众号能一起管理吗？**

A：可以。公众号与头条、百家号一起进账号台账，登录态隔离，互不串号。

**Q：AI 写的公众号文章 AI 味重怎么办？**

A：写完后可以过一遍「必过朱雀」本地改写，降低 AI 特征；也可以先用两遍式写作（先事实与结构、再文风精修）。
